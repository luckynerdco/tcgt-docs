Once your locations are set up, you can start adding cards to your inventory.

<Aside type="note">
Before adding stock, make sure Inventory Management is enabled. See the
[Overview](/inventory-management/overview/) for how to turn it on, and
[Locations](/inventory-management/locations/) for setting up storage.
</Aside>

## Adding stock

<Steps>

1. **Go to the Inventory tab in your dashboard**

2. **Click Add Stock**

3. **Search for the card you want to add**

4. **Select the condition and quantity**

5. **Choose which location to assign the stock to**

6. **Click Save**

</Steps>

<Aside type="tip">
You can set the quantity for each location when adding stock. This lets you split a
single card across multiple locations if needed.
</Aside>
