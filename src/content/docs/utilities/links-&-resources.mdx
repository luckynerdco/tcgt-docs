# Links & Resources

This page contains useful TCGTracking tools and resources that can help you check USPS activity, monitor TCGTracking services, and view marketplace processing activity.

## USPS Flow

https://tcgtracking.com/uspsflow.php

USPS Flow provides a visual look at how mail moves through the USPS network.

It can be useful for viewing USPS processing activity and understanding how mail travels through different parts of the network.

## TCGTracking Status

https://status.tcgtracking.com/

The TCGTracking Status page shows the current status of TCGTracking services.

If something appears to be unavailable or not working correctly, check this page for active incidents, service interruptions, and recent status updates.

## USPS Scan Rate Heatmap

https://tcgtracking.com/heatmap.php

The USPS Scan Rate Heatmap shows scan performance across different locations.

This can help identify areas where USPS first scans are performing well and areas where scan rates may be lower.

## TCGTracking Alternate Site

https://tcgtracking.app/

The TCGTracking alternate site can be used if the main TCGTracking website is unavailable.

If you are unable to access the main site, try the alternate site before assuming that TCGTracking is completely down.

## Global Marketplace Queues

https://tcgtracking.com/dashboard.php?tab=global-queues

The Global Marketplace Queues page shows live marketplace API activity.

You can use it to monitor marketplace API requests, requests currently being processed, and completed requests.

This can be useful when waiting for marketplace actions to complete or when checking whether marketplace requests are actively being processed.
